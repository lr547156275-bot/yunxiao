# Active round-aware algorithms

The active controllers are original HPCC (mode 3), original DCQCN (mode 1),
HPCC Round Reset (mode 11), CRFM Gate (mode 12), and Round-Safe HPCC (mode
13). The former empirical carry/recovery controller is disabled.

See `rs_hpcc_algorithm.md` for the active mode-13 equations and feedback
semantics.
