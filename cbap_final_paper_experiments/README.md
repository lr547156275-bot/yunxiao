# CBAP final paper experiments

This directory contains the preregistered 1408-run ns-3 experiment framework
for frozen CBAP-v1.3 (CC_MODE 25). Preparation does not run simulation.

Start with `scripts/run_preflight.sh`. Do not start the formal matrix unless all
seven preflight runs pass. See `reports/run_instructions.md` for commands and
`manifests/manifest_counts.json` for exact counts.
