# Metric definitions

The authoritative definitions are implemented by
`cbap_final_metric_pipeline/scripts/collect_full_work_metrics.py` and versioned
as `cbap_full_work_metrics_v1`. Newcomer CCT starts at application readiness;
incumbent and all-work metrics include every planned application byte. Queue AUC
uses timestamped integration. Unreconstructable dynamic-PFC threshold time is
reported unresolved, not inferred.
