# BUILD_AND_ENVIRONMENT — v2 campaign

## Code base
- ns-3.18 (`simulation/VERSION`), carrying the Alibaba HPCC simulator
  modifications (upstream: https://github.com/alibaba-edu/High-Precision-Congestion-Control),
  plus the CBAP-SBA controller and the v2 harness fixes (see
  `GIT_PROVENANCE.txt` and `v1_to_v2.patch` in this directory).
- v1 freeze point: commit `0c090e4`; v2 evidence lineage per
  `GIT_PROVENANCE.txt`.

## Build environment (docker container `hpcc-build` on a GitHub Codespace)
- OS: Ubuntu 20.04.6 LTS (container), host kernel 6.8.0-1052-azure
- Compiler: gcc/g++ 9.4.0 (Ubuntu 9.4.0-1ubuntu1~20.04.2)
- Build: `cd /work/simulation && ./waf build` (debug profile,
  `libns3.18-*-debug`, NS_ASSERT active)
- Run: `LD_LIBRARY_PATH=/work/simulation/build
  build/scratch/third <config.txt>`
- Machine: 4 vCPU / 16GB codespace; cells single-threaded; pools of 2
  parallel cells (parallelism affects wall clock only — determinism twin
  proves bit-identical outputs)
- Python: 3.8.10, standard library only (csv/tarfile/hashlib); no third-
  party analysis dependencies

## Physical constants and conventions
- Packet: payload 952B + 48B headers = wire 1000B exactly; per-packet tx
  time 800 / 40 / 20 ns at 10/200/400G — integer nanoseconds by
  construction (`TX_TIME_ROUND_NS 1` rounds both the qbb device
  serialization and the QP pacing timer; the legacy double-floor is kept
  as default-off for v1 byte-compatibility)
- Time resolution: 1 ns (ns-3 integer TimeStep throughout)
- Link rates: topology strings `10Gbps/200Gbps/400Gbps`, WIRE bits/s;
  payload rate = wire × 952/1000
- Topology: 89 nodes / 21 switches, multi-tier; per-link propagation
  1µs; measured base RTT (incl. 1-MTU serialization per hop):
  15,044 ns @10G, 12,152 ns @200G, 12,076 ns @400G (printed
  `maxRtt` in every cell log); BDP window = maxRtt × rate / 8
  (HAS_WIN 1, VAR_WIN 0, fixed for all arms)
- ECN: switch egress marking per `KMIN_MAP/KMAX_MAP/PMAX_MAP`
  (`switch-node.cc` / `switch-mmu.cc`); values are KB in the rate-indexed
  map rows
- PFC: priority pause per `switch-mmu.cc` dynamic thresholds,
  `QbbNetDevice` pause handling (`qbb-net-device.cc`), PAUSE_TIME 5µs;
  pause/resume frames logged to `pfc_events.csv`, cumulative pause time
  via `pfc_pause_ns_delta` in the link timeseries
- CC engines: DCQCN/DCTCP/TIMELY/HPCC in `rdma-hw.cc` (CC_MODE
  1/8/7/3); CBAP-SBA = CC_MODE 30 (admission/planning in `cbap-sba.cc`,
  controller in `rdma-hw.cc`)
- Config parser and workload replay: `simulation/scratch/third.cc`;
  all v2 cells generated by `tools/mk_v2.py` (this directory)

## Reproduction
1. checkout the commit in `GIT_PROVENANCE.txt` (or apply
   `v1_to_v2.patch` onto `0c090e4`)
2. `./waf build`
3. `python3 mk_v2.py matrix` (writes configs + `MATRIX_TAGS.txt`)
4. `run_v2matrix.sh` (determinism twin, 2-worker pool, DONE markers)
5. `python3 matrix_analyze.py` → `final_results_v2.csv`
Outputs are deterministic; byte-identical reruns expected (single seed
justified by the recorded twin).
